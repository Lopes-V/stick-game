# Godot runtime bundled with Chaos Stick Arena

This folder contains the official portable Godot Engine 4.7.1 Windows runtime
used by `HOST_GAME.bat` and `BUILD_WEB.bat`.

- `Godot_v4.7.1-stable_win64_console.exe`: dedicated/headless server runtime.
- `Godot_v4.7.1-stable_win64.exe`: editor/export runtime.
